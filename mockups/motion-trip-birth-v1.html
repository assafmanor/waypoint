Why the board, and not confetti

The zero state already renders the departure board unpowered; Trip Home renders it live and glowing. Between them sits creation, rendering no board at all — so the payoff is not something to invent, it is a gap to close. And the first row of a brand-new trip is honest content: the trip itself, departing in N days.

Confetti was drawn and rejected. It bolts a second metaphor onto an app that already has one, it spends the one-loud-element ration twice — the board is already the loud thing on screen — and it reads as generic where the board reads as this product. The 🎉 glyph stays; the burst does not.
It does not ask for a second cinematic moment. design-language allows exactly one (--t-cinematic, Plan→Trip). The cinematic asset is the board's power-on, and this is that same asset on a second trigger — one signature at the two moments a trip changes state (it is born; it goes live). Every other beat here is --t-deliberate or below.

The shared element is the argument

The draft card (.draft, today an aria-hidden decoration that silently swaps text) is one DOM node for the whole sequence — it travels from its slot in the form to the born card's position. Nothing cross-fades and nothing is duplicated: the card you were looking at is the card you end up with.

And the dashed → solid is not decoration. ADR-0011's soft/hard grammar means "provisional → committed", and this is the exact frame where the trip stops being a draft. The טיוטה tag leaves on the same beat. The motion is saying the one true thing about the moment — which is the test for whether a set piece has earned its length.

Proofs & controls

Skip by tappart of the design, never a setting
Reduced motionmust land the END state, not skip the outcome

Skippability is the load-bearing one. Someone who just wants to start planning must be able to land the whole thing with a tap — a celebration you cannot interrupt is a modal dialog wearing a costume. Turn it off and play A to feel why: the same 1450ms goes from generous to imposed.
Reduced motion is not "skip the moment". The board still ends up on, the card still ends up committed, the invite still appears — all of it arrives in one frame. A user who asked for less motion did not ask for a different outcome.

What this file cannot settle

Whether A's 1450ms reads as generous or as slow on the third trip you create — the first time it is a gift, and a set piece is judged on the repeat. If it wears, the fix is rarity rather than speed: play A on a person's first trip and B on every one after, which is one condition and no new design. Judge on a device before wiring it.

Status: proposal. Depends on motion-primitives-v1.html's G1/G2 — the born screen's own overlays and the route into it should already move correctly before this lands, or the set piece is a polished beat wired between two hard cuts. Also drawn here: the CTA arming when the form completes (beat 0), which is small, separable, and worth shipping even if neither candidate is.
